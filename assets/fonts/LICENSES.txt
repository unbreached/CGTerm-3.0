Fonts used by CGTerm's menus and intro
======================================

CGTerm does not load font files at run time. It uses the .bmp glyph
sheets in this folder, which were rendered from the fonts below with
tools/make_font.py. The licence notes are taken from each font's own
embedded copyright and licence fields, or from the licence file that came
with it.
