# CGTerm 3.0 - Code Review, Fixes and Roadmap (2026-10-05)

Scope: every file under `src/`, the Makefile, `scripts/`, `platform/` and
`tools/`. Five module reviews (transfer protocols, disk images, network and
rendering, UI/config/keyboard, audio/modem/build) were cross-checked by hand
against the code before anything was changed. Every fix listed under
"Fixed" is in the working tree on branch `color-fonts`, uncommitted.

Verification:

- `make` builds cgterm, cgchat, cgedit and testkbd with no compiler warnings
  (the two `ld: reducing alignment` notes are pre-existing and harmless).
- `make test` runs two new regression harnesses under `tests/`:
  `test_diskimage` (D64/D71/D81 geometry, BAM, directory, chains, error-byte
  images) and `test_xfer` (XMODEM receive/send and Punter receive against a
  scripted peer with a virtual clock). Both pass.
- Not verified on hardware: real BBS sessions, Windows and Linux builds.

The uncommitted `src/xmodem.c` change that was already in the tree (purge
stale bytes before the opening handshake, ignore non-header bytes) was kept;
its one weakness (the ignore path reset the timeout counter, so an echoing
host could keep the receiver busy forever) is fixed below.

## 1. Fixed in this pass

Severity is the impact before the fix. File references point at the current
code.

### Networking (src/net.c)

- HIGH. Raw-mode receive (used by every transfer protocol) did not collapse
  `IAC IAC` into one 0xFF on Telnet-negotiated links, while the send side
  already doubled outgoing 0xFF. Any Punter or XMODEM download containing a
  0xFF byte from a board behind a real telnet daemon failed its checksum or
  was corrupted. Raw receive now runs the same IAC layer once the peer has
  negotiated Telnet; raw TCP boards are still passed through untouched.
- MEDIUM. Every `send()` on the non-blocking socket ignored its return
  value; under back-pressure (board writing to disk) bytes were silently
  dropped from upload blocks. `net_write()` now waits for writability (up
  to 5 s) and disconnects on a hard error.
- MEDIUM. No SIGPIPE protection: a write after the peer reset the
  connection killed the whole process. SIGPIPE is ignored and
  `SO_NOSIGPIPE` / `MSG_NOSIGNAL` are used where available.
- LOW. "Telnet seen" was set by any 0xFF byte, so a raw C64 board printing
  PETSCII pi (0xFF) ate that character plus the next byte and switched
  outgoing 0xFF escaping on. Detection now requires a real negotiation
  command; a lone 0xFF from a raw board is delivered with its follower.
- LOW. `connect()` return value ignored; refused connections reported as
  "timed out"; Winsock failure signalled via exceptfds never detected.
  Immediate failures and `SO_ERROR` are now reported with `strerror`.
- LOW. `EINTR` on `recv()` disconnected the session.
- LOW. An escaped `IAC IAC` followed by 0xF0 inside a subnegotiation ended
  it early and leaked bytes to the screen.
- LOW. `net_connect()` never closed an existing socket (modem fallbacks and
  redial could leak a connection).

### XMODEM (src/xmodem.c)

- HIGH. The sender's wait for the receiver's NAK/'C' never exited on
  disconnect and had no time limit: a hard 100 % CPU loop with a frozen
  window. Now fails fast on disconnect or CAN and gives up after 60 s.
- MEDIUM. The sender's data loop ignored ESC and treated a timeout as "wait
  again forever". It now resends the outstanding block on timeout (ten
  tries) and honours cancel.
- MEDIUM. The pending "ignore junk bytes" change reset the timeout counter
  on every loop pass, so a host echoing the handshake character kept the
  receiver spinning indefinitely. Timeouts now accumulate until a valid
  block arrives and more than 2048 junk bytes abort with a message.
- LOW. After the first block an inter-block timeout sent ACK instead of
  NAK, letting the sender run one block ahead.
- New: three unanswered 'C' handshakes fall back to checksum mode (old C64
  XMODEM senders never answer 'C'); a 0-byte upload sends just EOT instead
  of "Read error".

### Punter (src/punter.c)

- HIGH. A data block carrying exactly one data byte (8 bytes total) was
  treated as a setup block and discarded, so every file whose length is
  1 mod 247 (248, 495, ...) lost its last byte with "Transfer complete".
  Covered by `test_xfer`.
- MEDIUM. A block the sender re-transmitted after missing our GOO/ACK was
  appended a second time. A block-number guard now acknowledges it without
  saving. Covered by `test_xfer`.
- MEDIUM. Uploads failed after a single 3 s silence waiting for S/B; a C64
  board writing to a real 1541 can be quiet longer. Now waits up to ~60 s.
- MEDIUM. Every upload announced file type PRG; `.seq` / `,s` files are now
  announced as SEQ (`punter_send_filetype`, set from the file name).
- LOW. Disconnect detection in the GOO loop and the S/B scan; the handshake
  loop honours ESC; an empty file sends the terminating block instead of
  wedging both sides.

### Transfer layer (src/xfer.c, src/ui.c, src/ui_term.c)

- HIGH. Multi Punter receive loops spun at 100 % CPU with no event pump
  when the connection dropped; the window had to be killed.
- MEDIUM. Multi Punter upload announced each file name before opening the
  file; when the open failed the board was left inside a Punter receive and
  the next announcement landed in it. Files are opened first; a failed
  transfer stops the batch; only successful files are counted and failures
  are reported.
- MEDIUM. Upload results were ignored: "Upload complete!" appeared after a
  cancelled or failed transfer. `xfer_send()` now returns a status and the
  messages reflect it.
- MEDIUM. A completed download was orphaned in /tmp when the name prompt
  was cancelled with ESC or the name was rejected by the validator. A bad
  name now re-prompts, ESC discards explicitly, and a stale temp file is
  reclaimed before the next download.
- MEDIUM. Saving into a disk image deleted the download before the image
  had actually been written back; a write-back failure now keeps the
  download and says so.
- LOW. Temp upload files leaked on a failed image extraction; USR files can
  now be extracted; extraction and Multi Punter use the entry's exact
  PETSCII name; a download path that is a plain file is detected; `,r` is
  accepted as REL; a truncated destination is removed on write error; the
  hex feed no longer shows the disconnect code as a byte.

### Disk images (src/diskimage.c, src/dir.c, src/fileselector.c)

- HIGH. The directory was walked from the BAM sector instead of the
  directory header. Identical on D64/D71, but on a D81 (40/1 vs 40/0) file
  lookup, delete, rename and duplicate detection never worked, each save
  allocated a fresh directory block, and once a track filled up the BAM
  bitmap could be overwritten with a file name.
- HIGH. `di_format()` for D81 never wrote the 40/3 link, the 'D' DOS byte
  or the zero at offset 3, so every image created by "New disk image" had
  an unreachable empty directory.
- HIGH. The D71 second-side allocation gate indexed 53/0 bitmap bytes as if
  they were free counts: tracks 62-70 were never used and "disk full" fired
  with about 170 blocks free. Allocation now gates on
  `di_track_blocks_free()` for every image type.
- MEDIUM. File data was allocated on the directory track, so the cached
  free count drifted from the BAM and the directory could not grow.
- MEDIUM. A disk-full write left an unclosed entry owning every free block
  that could neither be deleted nor overwritten. `di_close()` now rolls the
  incomplete file back (blocks freed, entry cleared), like VALIDATE.
- MEDIUM. A bad chain link made `di_read()` silently continue from block
  1/0, returning another file's data with status 0. It now stops with
  status 66; `di_open()` refuses an invalid start block.
- MEDIUM. `di_sync()` / `di_free_image()` swallowed every write failure.
  Both return a status now and the callers check it.
- MEDIUM. Names taken from a listing were used as wildcard patterns, so
  deleting a file called `A*` scratched every file starting with A. Exact
  byte-for-byte delete, rename and open were added and the file selector
  uses them; rename refuses an existing name.
- LOW. Freeing an already free block wrapped the per-track count; looped
  chains are now cut; a 0-byte file gets one block instead of pointing at
  block 1/0; the directory-sector probe is reduced modulo the track size;
  D81 format memsets no longer spill one byte into the next sector; REL
  files can be deleted (side sectors freed); allocation failure in
  `di_open("wb")` no longer leaves a half-made entry; images with a
  trailing error table (175531 / 351062 / 822400 bytes) load and the table
  is preserved on write-back; symlinked directories and DT_UNKNOWN
  filesystems are detected with `stat()`; the pseudo entries can no longer
  be tagged for upload; the UI compared against the wrong pseudo-entry
  text and read a successful delete (status 1) as failure; `dir_type[]` has
  the 8th entry the type mask needs; testimage no longer overflows its
  stack buffer.

### Terminal rendering (src/ansi.c, src/gfx.c, src/kernal.c, src/cgterm.c)

- MEDIUM. `ESC[?25l` (hide cursor) moved the cursor to 0,0 instead of
  hiding it, so the text that followed overwrote the top of the screen on
  almost every ANSI board. A real hidden-cursor flag was added
  (`gfx_cursor_show`) and is also used by the splash and background image.
- MEDIUM. `ESC[nA/B/C/D` used the PETSCII cursor primitives, which wrap
  lines and scroll; ANSI art using `ESC[40C` spacing or `ESC[25B` was
  mangled. They now clamp at the margins (and the scroll region); BS no
  longer wraps to the previous line.
- MEDIUM. SGR 7 (reverse) selected glyph+128 in the byte-ordered CP437
  font, drawing box-drawing characters instead of highlighted text. Reverse
  is now a foreground/background swap.
- MEDIUM. `termmode = ansi` in the config started the program with the
  PETSCII font and an all-black 256-colour table because `ansi_init()` only
  ran from the menu toggle.
- LOW. Truecolour `38;2;r;g;b` / `48;2;r;g;b` was parsed as separate SGR
  codes (nearest of 16 colours now); parameter array raised to 16; clear
  screen and scroll no longer leave a stray inverted cell; the background
  plane is cleared on scroll and shifted on insert/delete; a failed 40/80
  column switch no longer persists a half-applied layout.

### UI, configuration and keyboard

- HIGH. The keyboard layout selector pointed `cfg_keyboard` at a stack
  array that died when the menu returned (src/menu.c).
- MEDIUM. Macro recording never captured RETURN, cursor keys, HOME, DEL,
  INS, TAB, space or F-keys, so a recorded login played back as one run of
  letters (src/keyboard.c).
- MEDIUM. ANSI mode dropped TAB and every Ctrl+letter (src/keyboard.c).
- MEDIUM. "Load SEQ file" sent the file to the board unpaced instead of
  displaying it locally: the +256 "local" flag was lost in an
  `unsigned char` (src/cgterm.c).
- MEDIUM. Config values containing spaces were truncated at the first space
  (e.g. a Windows download directory under `C:\Users\John Smith`); the
  parser now takes the rest of the line and expands a leading `~/`
  (src/config.c).
- MEDIUM. Bookmark delete shifted alias/host/port but not the ANSI flag;
  quick-dial digits ignored the bookmark's terminal mode and the window
  title; editing a bookmark could leave NULL strings that were later
  formatted with `%s` (src/ui.c).
- LOW. `host =` in the config and cgchat's command line required a dot
  (`localhost` rejected); aliases with bytes above 0x7F were rejected; the
  config save deleted the original before renaming and ignored write
  errors; `-z` and the command-line port are range-checked; an unknown
  option now exits; cgchat used `strncpy`/`strcat` on a 1024-byte buffer and
  never re-read the defaults it wrote; testkbd used `sscanf` with
  overlapping buffers.

### Audio and modem (src/music.c, src/sound.c, src/modem.c)

- HIGH. On macOS and Linux the sound-effect API was a set of printf stubs
  returning a fake id: the bell and the entire modem dial soundtrack were
  silent and the RING timeline was skipped. Effects are now mixed into the
  libopenmpt device's callback; the device stays open so effects play with
  or without music.
- MEDIUM. ESC during the dial audio printed "no carrier" and returned
  failure while the pre-flight TCP connection stayed open; two allocation
  fallbacks opened a second socket to the board. ESC now skips the rest of
  the soundtrack and proceeds to CONNECT; a genuine abort disconnects.
- LOW. `openmpt_module_get_metadata()` result leaked (and could be NULL);
  `music_shutdown()` destroyed the module without the audio lock;
  `SDL_OpenAudio` asked for an obtained spec it never honoured; modules now
  loop gaplessly via `set_repeat_count`; the `/tmp/cgterm-music.log` debug
  file is gone; WAV samples are converted to the device format instead of
  overwriting the live spec.

### Build and scripts

- MEDIUM. A native MinGW/MSYS build never defined `WINDOWS`, so the Unix
  code paths (readlink, libopenmpt) were compiled and the build failed.
  The Makefile now detects MinGW/MSYS and sets `-DWINDOWS`, `.exe`,
  `-lws2_32`.
- MEDIUM. `install-linux.sh` and `install-macos.sh` checked for SDL_mixer
  (unused) and never installed libopenmpt (required).
- LOW. Hardening flags are repeated at link time (MinGW needs libssp);
  `make clean` no longer deletes the release zips in `dist/`
  (`make distclean` does); `make uninstall` and `make test` added;
  libopenmpt is located with pkg-config; a missing `sdl-config` is an error
  instead of a cascade of include failures; `curl -f` and a checked
  `unzip` in the cross-compile script; `package-macos.sh` checks for
  dylibbundler.

### Behaviour changes worth knowing

- Downloads from a board that negotiated Telnet now pass through the IAC
  layer. If a bridge negotiates Telnet but sends raw 0xFF inside transfer
  data (a protocol violation), those transfers will now fail where they
  previously happened to work; raw-TCP boards are unaffected.
- A disk-full save into an image no longer leaves a partial file in the
  image; the download is kept in the temp file and can be retried on
  another image.
- ESC during the modem dial animation no longer hangs up.
- `make clean` keeps `dist/`.

## 1b. Second pass (same day): features and the remaining findings

Everything in section 2 below that is marked "done" was implemented in a
second pass, together with the feature roadmap items listed here. The
previously open findings that are now fixed: bookmark editor sanitising and
alias clamp; Windows per-user files under %APPDATA%\CGTerm with one-time
migration; non-blocking ESC confirmation during transfers; Rainbow start
purge and timeout-only retries; clipboard CR/LF across chunks and UTF-8
transliteration; notes longer than 255 characters and lines starting with
'['; font slot aliasing on runtime font swap; system config read before the
user config; reconnect after any drop; cgchat/cgedit default keyboard line;
build-installer.bat and the NSIS script agree on dist\win32;
install-macos.sh uses the self-contained bundle; DATADIR honoured by
paths.c; platform/macos dead code removed; directory listing sorted with
qsort; per-user debug log.

Implemented features (all in the tree, all built and tested where a test
without a real board is possible):

  ZDATA/ZEOF/ZFIN, hex and binary headers, CRC-16 and CRC-32, ZDLE
  escaping, ZRPOS recovery, ZSKIP, cancel. Auto-started from the terminal
  when the ZRQINIT sentinel is seen (Options: A). Tested against lrzsz.
- Transfer menu remembers the last protocol and direction (T + Return).
- Transfer log (~/.cgterm-transfers.log) and on-screen summary with bytes,
  seconds and cps for every transfer, including Multi Punter and ZMODEM
  files.
- Status row under the terminal (Options: L): board, PETSCII/ANSI, 40/80,
  capture, macro recording, login script, clock, redial countdown.
- Capture to file toggled at any time (Options: C), timestamped lines,
  appended; -o / logfile= still work.
- Copy screen text to the clipboard (menu X), PETSCII and CP437 mapped
  to ASCII.
- Connection history viewer with redial (menu Y); redialing a host that is
  bookmarked applies the bookmark's terminal mode and login script.
- Per-bookmark auto-login scripts: a "login=" line in the bookmark note
  (w:TEXT wait, s:TEXT send, cr, p:N pause), paced through the paste queue,
  30 s wait timeout, aborted on disconnect.
- Options panel (menu O): sound on/off, music volume, send and receive
  delay, zoom 1x-4x at runtime, status line, auto ZMODEM, transfer log,
  capture, local echo. All persisted.
- Keyboard menu lists every .kbd file in the assets directory.
- IPv6 with IPv4-first fallback across all resolved addresses; proactive
  Telnet negotiation (TTYPE, NAWS, SGA) in ANSI mode; NAWS resend on a
  40/80 switch.
- ANSI emulation completed (scroll regions, pending wrap, DECSC/DECRC, RI,
  ICH/DCH/ECH/IL/DL, CHA/VPA/HPA/CNL/CPL, iCE colours, BCE, DA/DSR,
  alternate screen, origin mode, DEC line drawing, OSC skipping) with
  xterm key sequences, Alt+letter and Shift+PgUp/PgDn local scrollback;
  91-check regression test under the SDL dummy video driver.
- Disk tools in the file selector: V validate (rebuild BAM, drop splat
  entries), L lock/unlock, X extract to the host folder or insert host
  files into the download image, I disk info and rename disk/ID; CBM-style
  listing with blocks, type, splat and lock markers and the header line.
- Mutation fuzzer for the disk-image parser (make fuzz, sanitizers on);

- GitHub Actions workflow building Linux, macOS and MinGW and running the
  tests; make uninstall and make distclean.

Still not done, and why:

- TLS (telnets): needs OpenSSL or mbedTLS on every platform and in the

- macOS notarization: needs an Apple Developer account; the README now

- Scrollback is line-by-line (PageUp/PageDown, Shift+ in ANSI mode); a

- Mouse selection, C64 logical-line linking in PETSCII mode, GEOS/VLIR
  detection, D81 partitions, REL side-sector creation on write.
- Validate does not rewrite per-entry block counts (real CBM DOS does not
  either).

## 2. Found, not fixed

Ordered roughly by impact. All are good candidates for the next pass.

- MEDIUM. Bookmark editor accepts commas and other characters the bookmark
  file cannot round-trip; aliases are truncated to 27 characters by
  `addhost()` while the editor allows 63 (src/ui.c, src/config.c).
- MEDIUM. Windows per-user files (config, bookmarks, notes, history) are
  bare relative names resolved against the current directory; launching
  from a different folder "loses" the bookmarks (src/config.c).
- LOW. The ESC "Cancel transfer? (Y/N)" prompt is a modal busy-wait that
  stops consuming the socket; answering slowly can time out the sender
  (src/xfer.c `xfer_check_kbd`). Needs a non-blocking prompt.
- LOW. Rainbow receive counts every stray byte before SOH against its ten
  retries and has no stale-byte purge (src/rainbow.c).
- LOW. Clipboard paste: a CR/LF pair split across 4096-byte chunks yields a
  blank line; UTF-8 bytes are forwarded raw to PETSCII boards
  (src/clipboard.c).
- LOW. Bookmark notes longer than 255 characters are split with spurious
  newlines on reload and a note line starting with `[` is read as a
  section header (src/config.c).
- LOW. Runtime font swap frees an aliased font slot (double free later) and
  leaks the previous body font (src/menu.c 1830-1850).
- LOW. The file selector's F2 "save path" appends a raw `dldir =` line with
  `fopen("a")` on every press instead of `cfg_save_setting()`
  (src/ui_term.c).
- LOW. Once `~/.cgtermrc` exists (even with one key), the system config is
  never read again, so bookmarks from `/etc/cgterm.cfg` vanish after the
  first saved setting (src/cgterm.c, src/config.c).
- LOW. Reconnect only re-dials if the drop happens within `reconnect`
  seconds of the last attempt; README advertises auto-reconnect.
- LOW. cgchat/cgedit write `keyboard = us.kbd` into their default config
  but only `default.kbd` ships.
- LOW. `build-installer.bat` and `cgterm-installer.nsi` still disagree on
  file locations; `install-macos.sh` still bundles only `cgterm` without
  dylibs and copies a `libmikmod.dylib` nothing loads; the cross-compile
  script still uses unverified archives under /tmp.
- LOW. `install-linux.sh` accepts a `DATADIR` override that `paths.c`
  never probes.
- LOW. `platform/macos/SDLMain.m` is dead code.
- LOW. Directory listings are bubble-sorted on every read (slow on folders
  with thousands of files).
- LOW. The transfer debug log is a fixed `/tmp/cgterm-debug.log`.

## 3. Suggested features, functions and changes

Grouped by what makes the biggest difference for someone who actually uses
the program to call C64 boards. Items marked (June) were already listed as
INFO in REVIEW-2026-06.md and are still open.

### Tier 1: transfers and session (highest value)

1. Auto-start of transfers. Detect the Punter "GOO" / Multi Punter 0x09
   announcement / XMODEM start / ZMODEM `rz` sentinel in the incoming stream
   and offer (or just start) the matching receive. Today a download is four
   menu steps away. (June)
2. ZMODEM and YMODEM batch. Most telnet-era boards (Image, C*Base over
   bridges, PC boards with C64 areas) offer them; ZMODEM carries file name,
   size and resume, so XMODEM's "enter a name" prompt disappears.
3. Transfer summary and log: bytes, CPS, retries, per-file result for Multi
   Punter batches, written to a per-user transfer log. Today a failed file
   inside a batch is invisible.
4. In-session capture toggle (start/stop/append to a chosen file) and a
   session header line; today logging is only `-o` at start-up. (June)
5. Terminal status line: host, PETSCII/ANSI, 40/80, capture on/off, current
   transfer. The status module exists but is only wired into cgchat. (June)
6. Runtime settings without restart: sound/music mute and volume, baud
   emulation (send/receive delay), local echo, zoom, resizable window.
   (June)
7. Connection history viewer with redial, bookmark reordering and search,
   quick-dial beyond slots 0-9, per-bookmark auto-login macro. (June)
8. TLS (telnets) and IPv6 with multi-address fallback, since more boards sit
   behind TLS front-ends and dual-stack hosts. (June)
9. Non-blocking ESC confirmation during transfers (keeps draining the
   socket while asking).

### Tier 2: disk-image tools

10. VALIDATE (rebuild the BAM from the chains) and a "collect" report;
    this also repairs images damaged by the bugs fixed above.
11. Disk-level operations from the selector: rename disk and ID, lock and
    unlock files, close splat files, show the DOS header line
    (`0 "NAME" ID 2A`), show splat (`*`) and locked (`<`) markers.
12. Copy and extract between an image and the host, image to image, and a
    "put whole folder into a new D64" action; create a new empty image from
    the selector.
13. 40-track D64 (196608 / 197376 bytes), D81 partitions and CBM
    subdirectories, REL files with side sectors, GEOS/VLIR detection.
14. PETSCII-accurate names in listings using the C64 font instead of `.`
    for anything outside 0x20-0x5F.
15. CBM DOS allocation order (start at 17/19 and move outward, 1581
    directory interleave) so images written back to real media behave like
    drive-formatted disks.

### Tier 3: terminal emulation

16. ANSI completeness for modern BBS software (Mystic, Synchronet,
    Enigma): scroll-region-aware LF and `ESC[S`, DECAWM and the VT "pending
    wrap" state, `ESC 7`/`ESC 8`, RI, ICH/DCH/ECH, CHA/VPA, blink-as-bright
    background (iCE colours), background-colour erase, proactive Telnet
    negotiation (WILL NAWS/TTYPE, DO SGA) and NAWS resend on 40/80 switch.
17. PETSCII fidelity: C64 logical-line linking so DEL/INS at a wrapped
    boundary behaves like the real machine; CHR$(141) distinct from CR.
18. Copy screen text to the clipboard and mouse selection; scrollback
    review mode with page keys. (June)
19. SEQ/PRG viewer with PETSCII rendering, screenshot to PNG and to SEQ.

### Tier 4: usability and platform

20. Keyboard layout menu that scans `assets/*.kbd` and accepts a custom
    file; document reconnect, logfile, Load/Post SEQ and the bookmark editor
    keys in `help.txt`. (June)
21. Windows: keep per-user files under `%APPDATA%\CGTerm`; make the native
    MinGW build part of CI; macOS notarisation (ad-hoc signing now requires
    "Open Anyway" on macOS 15); `.desktop` file and man page for Linux.
    (June)
22. CI running `make` on Linux/macOS/MinGW plus `make test`, and a
    fuzz harness for the ANSI/PETSCII parsers and the disk-image loader
    (both consume untrusted bytes).
23. Scripting: per-bookmark expect/send login scripts and a simple macro
    language, so "dial, log in, go to the file area" is one key.
24. Sysop and scene conveniences: import a BBS list (e.g. the telnet BBS
    guide) into bookmarks, a "boards to try" directory with notes, and a
    one-key "upload this whole D64 with Multi Punter".

## 4. Running the regression harnesses

```
make test
```

Builds `build/obj/test_diskimage` and `build/obj/test_xfer` and runs them.
They need no window and no network; scratch files go under `/tmp`.
`test_xfer` links the real `xfer.c`, `xmodem.c` and `punter.c` against a
scripted peer and a virtual clock, so the 60 s and 30 s timeout paths run
in milliseconds.
